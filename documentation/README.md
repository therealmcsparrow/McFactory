# McFactory documentation

McFactory shows your Claude Code activity as a live factory, and lets you chat with your sessions from that same page. These pages explain each part.

| Page | What it covers |
|------|----------------|
| [Getting started](getting-started.md) | Requirements, starting the server, every command-line option |
| [The factory view](factory-view.md) | What the halls, lines, arms and crates mean, and how status and "needs you" are worked out |
| [Chat and new sessions](chat.md) | Starting a Claude session from the dashboard, the chat panel, slash commands, skipping permission prompts |
| [Chat with terminal and desktop sessions](peer-chat.md) | Sending messages into sessions you started in the Claude CLI or desktop app |
| [Answer prompts from the dashboard](permission-hook.md) | The optional global hook that shows Allow / Deny cards for your terminal sessions |
| [Usage and plan limits](usage.md) | The Usage view: 5-hour and weekly limits, tokens and cost per model |
| [Desktop app](desktop-app.md) | The Windows app (Tauri) that wraps the same page |
| [HTTP API](api.md) | Every endpoint the page uses |
| [Security and privacy](security-and-privacy.md) | What the server accepts, what reaches the browser, what is stored |
| [Troubleshooting](troubleshooting.md) | Common problems and what to do |

For how to report a problem or send a change, see [CONTRIBUTING.md](../CONTRIBUTING.md). For security problems, see [SECURITY.md](../SECURITY.md).
